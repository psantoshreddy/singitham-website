# Singitham Website

A static marketing website for Singitham, built to present the company’s master data management (MDM) offering in a premium, dark-tech brand style.

## Overview

Singitham is positioned as an agentic AI MDM platform focused on helping small and mid-sized enterprises create trusted, clean master data without the cost and complexity of traditional enterprise MDM programs. The website communicates the value proposition, agent architecture, industry use cases, and booking flow.

## Current project state

The site has been developed as a multi-page static website with a strong visual identity and consistent landing-page structure.

### Pages included

- Home page: value proposition, hero section, pipeline diagram, agent stack, trust stats, CTA
- About page: founder story and positioning
- Use Cases page: industry-specific MDM examples for Finance, Automobile, Retail, and Healthcare
- Book a walkthrough page: inquiry form with mailto submission flow

### Design direction

- Dark-themed interface with amber/blue/teal accents
- Premium SaaS-style branding
- Large editorial typography with modern tech aesthetic
- Sticky navigation and conversion-focused CTA buttons
- Responsive layout for smaller screens

### Key messaging areas

- Agentic AI + MDM positioning
- Four-agent pipeline: Sourcing, Data Quality, MDM, and Provisioning
- Value proposition focused on speed, lower cost, and operational clarity
- Industry-specific examples showing real-world MDM challenges

## Tech stack

This project is currently built with plain web technologies:
